# 网格重建算法

## 为什么不用普通描边

像素 logo 被放大成 JPG 后，边缘有压缩噪点和抗锯齿。Potrace 类描边会把台阶变成抖动曲线。先恢复整数网格，再输出矩形路径，放大后更接近原设计。

## 步骤

### 1. 估计格宽 `period`

对灰度做列/行差分，看自相关。像素风常见 16/20/24/32。1024 图上这次任务的主周期是 20。

也可用「格内颜色方差」打分：把图画成 `period × period` 的格子，只统计非背景格的平均方差。方差最低的 `(period, ox, oy)` 就是对齐方式。

搜索时用 numpy reshape，避免 Python 双层循环超时：

```python
crop = im[oy:oy+H, ox:ox+W]
cells = crop.reshape(gh, period, gw, period, 3).swapaxes(1, 2)
var = cells.reshape(gh, gw, -1, 3).var(axis=2).mean(axis=2)
```

### 2. 每格取中位数颜色

JPEG 均值会被脏像素拉偏，中位数更稳。

### 3. 抠背景

背景常是单一深色（本次为约 `(15, 26, 44)`）。像素到背景的欧氏距离小于 `--bg-dist` 则视为透明。`--auto-bg` 用全图出现最多的颜色当背景。

### 4. 合并相近色（无 sklearn）

对前景格做贪心聚类：按出现顺序，若与已有中心距离 ≤ `--thresh` 则并入并更新均值，否则新建类。

经验：

- `thresh=10~14` 保高光、保交接混色（本次用 14，34 色）
- `thresh=18~24` 更像品牌减色稿
- 单格杂色往往是 JPG 抗锯齿。用户说「尽量不简化」就留；说「干净 logo」就并进最近大类

### 5. 裁切与合并矩形

内容包围盒加 `--pad` 格边距。先横向 run-length，再把上下相邻、同 `x/w` 的 run 合成更高的 rect。

绘制顺序按亮度升序，避免深色盖住高光。

### 6. 目视验收

必看：

- 圆形/圆角块的高光格还在不在
- 箭头/斜边台阶有没有错一格
- 背景是否抠干净（边缘不该留一圈深底）
- 杆与主体交接处的过渡色是否被并没

错位时优先改 `ox/oy`，不要先加大 `thresh`。
